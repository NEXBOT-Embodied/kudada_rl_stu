# Day1 课前准备清单

本页列出 Day1 前需要准备的基础知识、环境自查和带到课堂的材料。软硬件要求、环境安装和验证命令见 [学生 README](../README.md)。每组至少一台电脑完成环境验证，每位学员完成下面的知识自查。

## 课前必备基础知识

目标是能够跟随实验操作、读懂简单代码并记录结果。请按下表检查自己的操作能力，把不熟悉的内容记下来，课前补习或向教师反馈。

| 内容 | 课前应能完成的操作 |
|---|---|
| 命令行与文件路径 | 使用 `cd` 进入学生仓库；执行 `.\run.ps1 doctor`；找到相对路径 `configs/baseline.json` 和 `reports/local/`；保留完整命令与报错。Linux 使用 `bash run.sh`。 |
| Python 基础 | 理解数字、布尔值、变量、列表、字典、循环、函数和 `import`；能顺着一段简单脚本说明输入、计算过程和输出。 |
| JSON 配置 | 理解键和值、数字与字符串、嵌套对象；能在配置副本中修改一个数值并保存，保持引号、逗号和括号正确；能找到 `seed`、`num_envs`、`iterations`。 |
| 基础数学与单位 | 理解二维向量的分量与长度、平均值、速度与位移；区分有符号速度与速度大小，认识米、秒、米/秒、弧度和弧度/秒；知道角度与弧度需要换算。 |
| 机器人与反馈控制 | 区分关节目标角、实际角和关节速度；知道 IMU 用于感知身体运动、姿态需要由传感器信息估计；理解控制器会根据目标与实际状态的差异调整关节。 |
| 强化学习基础 | 能用站立实验说明智能体、环境、观测、动作、奖励和策略；区分单步奖励与累计回报、回合与训练迭代，以及训练与评估。 |
| 对照实验与记录 | 能解释“只改一个因素”；知道保留同一起点、训练预算和评估条件；能保存配置、检查点、命令与报告，使用不同目录保存不同实验。 |

有基础的学员可安排 30–60 分钟复习与自测；刚接触 Python、命令行或强化学习的学员应提前补习，再完成环境安装。

## 强化学习基础预习（课前必读）

先阅读 [强化学习基础预习](rl_basics.md)，理解以下内容并完成文末自测：

- 智能体与环境如何形成“观测 → 动作 → 新观测与奖励”的交互过程。
- 状态与观测的区别，以及本课 Actor 输入的约定。
- 单步奖励、累计回报和折扣因子 `gamma` 的含义。
- 一步、回合、采样段、并行环境与训练迭代的区别。
- 探索的作用，策略与价值函数分别做什么。
- 训练与评估的区别，以及为什么要做相同条件的 A/B/C 对照。

课前目标是能用自己的话解释这些概念、算出简单的两步回报，并联系本课实验举例。PPO、GAE 的推导和实现将在课堂学习。

## 建议课前了解的课程概念

先能用自己的话解释这些词即可，具体实现会结合实验讲解。

| 概念 | 入门理解 |
|---|---|
| NumPy 数组与张量 | 用数组保存一组数值，`shape` 表示各维度大小；例如一组关节角和多组并行仿真的关节角，数据维度不同。 |
| 神经网络与策略 | 神经网络根据输入计算输出；策略根据观测生成动作，训练会调整网络参数。检查点保存训练后的模型及相关信息。 |
| PD 控制 | P 项根据目标角与实际角的差异产生控制作用，D 项根据关节速度提供阻尼作用；本课会结合零动作 PD 回放观察它们的效果。 |
| 训练、评估与导出 | 训练调整策略参数；评估在指定条件下测量表现；导出把模型转换成 ONNX，供推理程序加载。 |

课堂将讲授 PPO、GAE、Actor/Critic、奖励设计、观测历史与 ONNX 接口，并带领完成导出校验。课前先完成下面的基础知识自测，再浏览 [学生实验手册](student_lab.md) 的课程目标与实验流程。

## 基础知识自测

- [ ] 能说明 `seed` 用于随机种子、`num_envs` 用于并行环境数量、`iterations` 用于训练迭代次数，并在 `configs/baseline.json` 中找到它们。课前先阅读配置，课堂再按实验要求修改。
- [ ] 对前后方向速度 `+0.1 m/s` 和 `-0.1 m/s`，能算出有符号平均速度为 `0`，平均速度大小为 `0.1 m/s`，并解释为什么不能据此说机器人没有晃动。
- [ ] 当关节目标角为 `0.2 rad`、实际角为 `0.1 rad` 时，能算出角度误差为 `0.1 rad`，并说明它与关节速度是不同的量。
- [ ] 能区分“训练奖励提高”和“站立表现改善”，说明为什么需要在相同条件下评估并保留原始记录。
- [ ] 已读完 [强化学习基础预习](rl_basics.md)，能解释交互过程、累计回报、探索和回合，并完成文末六项自测。

## 课前自查

- [ ] 每组至少一台电脑准备好课程环境，已完整克隆或解压学生仓库，能够找到 `run.ps1` 和 `models/teaching_start.pt`。
- [ ] 已通过安装脚本建立本仓库 `.venv`，后续统一使用 `run.ps1`（Linux 为 `bash run.sh`），无需激活环境。
- [ ] `doctor` 的 `missing` 列表为空，`default_checkpoint_present` 为 `true`。
- [ ] PD 与 RL 两种 GUI 检查都能显示完整机器人并运行。
- [ ] Motrix 短评估正常结束，已生成 `reports/local/preclass/evaluation.json`。
- [ ] 能进入目录、执行命令，并打开阅读 Python、JSON 和 Markdown 文件。
- [ ] 已完成基础知识自测，并记录需要教师帮助的知识点。
- [ ] 已保存检查结果和完整报错，准备好电源适配器及鼠标。

教学起点的摆动属于预期现象；课前不用调参。短评估用于检查环境功能，课堂完整评估要求见 [实验手册](student_lab.md)。

## 带到课堂的材料

- 安装好的课程环境及完整学生仓库。
- `doctor` 输出、一次 GUI 截图、短评估报告。
- 个人电脑配置和安装中遇到的问题；有报错时附完整命令和输出。
- 基础知识自测中不熟悉的内容，以及希望教师重点讲解的问题。
- 对两个问题的初步想法：“零速度指令为什么仍可能晃动？”“怎样证明修改奖励确实带来改善？”

课程预习可浏览 [实验手册](student_lab.md) 的课程目标和 [仓库与模型说明](repository_guide.md)。

建议教师提前 3–7 天发放学生仓库，在开课前一天收齐环境检查结果，提前安排有安装问题的学员使用备用工位。
