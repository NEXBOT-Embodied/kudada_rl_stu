# Day1 课前准备清单

软硬件要求、前置知识、环境安装和验证命令统一见 [学生 README](../README.md)。本页用于完成后的自查和材料交接。

## 课前自查

- [ ] 每组至少一台电脑准备好课程环境，已完整克隆或解压学生仓库，能够找到 `run.ps1` 和 `models/teaching_start.pt`。
- [ ] 已选择安装方式，知道后续使用本仓库 `.venv` 还是显式指定 Conda 的 `-PythonPath`。
- [ ] `doctor` 的 `missing` 列表为空，`default_checkpoint_present` 为 `true`。
- [ ] PD 与 RL 两种 GUI 检查都能显示完整机器人并运行。
- [ ] Motrix 短评估正常结束，已生成 `reports/local/preclass/evaluation.json`。
- [ ] 能进入目录、执行命令，并打开阅读 Python、JSON 和 Markdown 文件。
- [ ] 已保存检查结果和完整报错，准备好电源适配器及鼠标。

教学起点的摆动属于预期现象；课前不用调参。短评估用于检查环境功能，课堂完整评估要求见 [实验手册](student_lab.md)。

## 带到课堂的材料

- 安装好的课程环境及完整学生仓库。
- `doctor` 输出、一次 GUI 截图、短评估报告。
- 个人电脑配置和安装中遇到的问题；有报错时附完整命令和输出。
- 对两个问题的初步想法：“零速度指令为什么仍可能晃动？”“怎样证明修改奖励确实带来改善？”

课程预习可浏览 [实验手册](student_lab.md) 的课程目标和 [仓库与模型说明](repository_guide.md)。PPO、GAE、奖励设计、观测历史和 ONNX 导出由课程讲授。

建议教师提前 3–7 天发放学生仓库，在开课前一天收齐环境检查结果，提前安排有安装问题的学员使用备用工位。
